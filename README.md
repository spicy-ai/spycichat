## English

### Creativity should move at the speed of imagination

Spicy AI is an independent AI image and video generation platform for creators, designers, marketers, studios, and developers. It brings the essential parts of visual creation into one streamlined experience: choose a generation mode, describe the idea, add a reference when needed, select the right model and parameters, generate, and download the result.

Instead of separating image experiments, animation, prompt discovery, and production integration across multiple tools, Spicy AI connects them in a single creative ecosystem. Creators can explore ideas in the web studio, learn from reusable prompts and public generations, then bring proven workflows into their own products through the API.

### One studio, four core generation modes

| Mode | Input | Output | Ideal for |
| --- | --- | --- | --- |
| **Text to Image** | A natural-language prompt | A newly generated image | Concept art, characters, campaign visuals, social content, and rapid ideation |
| **Image to Image** | A source image and creative direction | A transformed image | Variations, restyling, enhancement, and exploring a new visual direction while retaining the core composition |
| **Text to Video** | A scene, motion, or story described in text | A generated video | Short-form content, visual storytelling, motion concepts, and campaign experiments |
| **Image to Video** | A still image and motion instructions | An animated video | Bringing artwork, characters, product images, and visual concepts to life with movement and camera effects |

Available controls and output characteristics depend on the selected model. This model-aware approach gives casual creators a simple starting point while still supporting the parameters needed for more deliberate production workflows.

### Why creators choose Spicy AI

- **A unified workflow:** Create images and videos without constantly moving prompts, references, and outputs between disconnected products.
- **Fast iteration:** Image generations typically complete in about 10 seconds and video generations in about 200 seconds, although actual times vary by model, settings, complexity, and service load.
- **Professional visual output:** Generate high-resolution media with detailed subjects, lighting, composition, motion, and cinematic effects according to the capabilities of the chosen model.
- **Reference-driven creation:** Upload an image to preserve a visual starting point, explore variations, or animate a strong still into a video.
- **Watermark-free downloads by default:** Export finished media that is ready to use in creative projects.
- **Commercial-ready usage:** Use compliant generations in marketing, social media, client work, and other commercial projects, subject to the platform terms and the rights associated with the input material.
- **Flexible credit access:** New accounts currently receive 30 signup credits. Additional credits can be earned through available activities or obtained through subscriptions and credit packs.
- **Inspiration built in:** Browse public creations and reusable prompts to understand what works before starting a new generation.

### From an idea to a finished asset

1. **Create an account.** New users currently start with 30 credits and can obtain more through the options available on the platform.
2. **Choose a generation mode.** Start from text, an image, or a combination supported by the selected model.
3. **Describe the result.** Write a prompt, upload an optional reference, and adjust the available model parameters.
4. **Generate and iterate.** Review the output, refine the creative direction, and generate new variations when needed.
5. **Download or integrate.** Use the result in a project, or move the workflow into an application with the Spicy API.

Actual results depend on the selected model, account settings, prompt quality, input material, and applicable content rules.

### Built for real creative workflows

Spicy AI is designed for a wide range of visual work:

- **Artists and designers** can explore characters, compositions, styles, and motion before committing to a final direction.
- **Content creators** can produce images and short videos for social channels, communities, and storytelling projects.
- **Marketing teams** can prototype campaign visuals, product concepts, ads, and branded content more quickly.
- **Studios and professionals** can test storyboards, camera ideas, transitions, and visual treatments during pre-production.
- **Developers** can add AI image and video generation to applications through a documented, credit-based API.
- **Adult creators** can access supported private creative workflows where legally permitted and in compliance with platform policies.

### A platform for developers

The [Spicy API](https://spicyai.site/docs/api) provides a direct path from browser-based experimentation to product integration. Its workflow is intentionally straightforward:

1. Create an API key from the account dashboard.
2. Authenticate requests with a Bearer token.
3. Submit a generation request using a model ID and its model-specific payload.
4. Poll queued tasks until the generation succeeds or fails.
5. Read generation history and inspect account credits and membership status.

The documentation includes an API playground, model-specific payload fields, generation endpoints, task states, history access, and credit-based billing guidance. This makes it possible to validate a creative workflow in Spicy AI Studio first, then automate it without rebuilding the entire generation experience from scratch.

## 简体中文

### 让创作速度跟上想象力

Spicy AI 是一个独立的 AI 图片与视频生成平台，面向创作者、设计师、营销团队、工作室和开发者。平台把视觉创作所需的关键环节集中在一个简洁的工作流中：选择生成模式、描述创意、按需添加参考素材、选择模型与参数、生成并下载结果。

你不再需要在多个彼此割裂的工具之间搬运提示词、参考图和生成结果。你可以先在网页工作台中探索创意，通过提示词库与公开作品学习成熟用法，再利用 API 将验证过的生成流程接入自己的产品。

### 一个工作台，四种核心生成模式

| 模式 | 输入 | 输出 | 适用场景 |
| --- | --- | --- | --- |
| **文生图** | 自然语言提示词 | 全新生成的图片 | 概念图、角色设计、营销视觉、社媒内容和快速创意探索 |
| **图生图** | 原始图片与创作方向 | 转换后的图片 | 图片变体、风格转换、画面增强，以及在保留核心构图的基础上探索新方向 |
| **文生视频** | 用文本描述场景、动作或故事 | 生成的视频 | 短视频内容、视觉叙事、动态概念和营销创意测试 |
| **图生视频** | 静态图片与运动指令 | 动态视频 | 让插画、角色、商品图和视觉概念拥有自然动作、镜头运动与动态效果 |

可用参数和输出特征会随所选模型而变化。这种以模型能力为基础的设计，既为普通创作者提供简单的起点，也能满足更精细的制作需求。

### 为什么选择 Spicy AI

- **统一创作流程：** 在同一工作区内完成图片与视频创作，不必反复在不同产品之间转移提示词、参考素材和生成结果。
- **快速迭代：** 图片通常约 10 秒生成，视频通常约 200 秒生成；实际耗时会受到模型、参数、任务复杂度和服务负载影响。
- **专业级视觉输出：** 根据所选模型的能力，生成具有丰富细节、自然光影、清晰构图、真实运动和电影感效果的高分辨率内容。
- **参考图驱动创作：** 上传图片作为视觉起点，生成变体、探索新风格，或把优秀的静态画面制作成视频。
- **默认无水印下载：** 导出可直接用于创意项目的成品媒体。
- **支持合规商业使用：** 在遵守平台条款并拥有输入素材相应权利的前提下，可将生成内容用于营销、社交媒体、客户项目及其他商业场景。
- **灵活的积分体系：** 新账号当前可获得 30 个注册积分，还可通过平台提供的活动、订阅方案或积分包获得更多积分。
- **内置创作灵感：** 通过公开作品和可复用提示词了解成熟案例，再开始自己的生成任务。

### 从创意到成品

1. **创建账号：** 新用户当前可获得 30 个积分，也可通过平台提供的方式继续获取积分。
2. **选择生成模式：** 从文本、图片或所选模型支持的输入组合开始创作。
3. **描述目标效果：** 编写提示词，按需上传参考图，并调整模型提供的参数。
4. **生成并迭代：** 检查输出结果、优化创作方向，并在需要时生成新的版本。
5. **下载或接入产品：** 将结果用于项目，或通过 Spicy API 把生成能力集成到应用中。

实际输出取决于所选模型、账号设置、提示词质量、输入素材和适用的内容规则。

### 面向真实创作场景

Spicy AI 可用于多种视觉工作：

- **艺术家和设计师**可以在确定最终方向前，快速探索角色、构图、风格和动态效果。
- **内容创作者**可以为社交平台、社区和叙事项目制作图片与短视频。
- **营销团队**可以更高效地测试营销视觉、产品概念、广告和品牌内容。
- **工作室和专业团队**可以在前期制作中验证分镜、镜头、转场和视觉风格。
- **开发者**可以通过文档完善、按积分计费的 API，把 AI 图片与视频生成能力接入应用。
- **成人创作者**可在法律允许并遵守平台政策的地区使用平台所支持的私密创作工作流。

### 面向开发者的平台能力

[Spicy API](https://spicyai.site/zh/docs/api) 为网页端创意验证与产品集成之间提供了直接通道，整体流程保持清晰简单：

1. 在账号控制台创建 API Key。
2. 使用 Bearer Token 完成请求认证。
3. 使用模型 ID 和对应的模型参数提交生成任务。
4. 对排队中的任务轮询状态，直到生成成功或失败。
5. 读取生成历史，并查询账号积分与会员状态。

API 文档提供在线调试工具、各模型专属参数说明、生成接口、任务状态、历史记录和积分计费指南。你可以先在 Spicy AI Studio 中验证创作流程，再将其自动化，而不必从零搭建完整的生成体验。
